PsychApp v0.1: the first public concept

Milestone // 2026-06-25Retrospective published // 2026-07-26Status // historical conceptVersion label // portfolio milestone, not a Git tag

The original PsychDeep post remains unchanged. This later note records what the first public concept demonstrated, what it could not prove and why the project moved toward a narrower, clinician-supervised research architecture.

Read the original postContinue to v0.2PsychApp repository

What the 2026-06-25 milestone was

The first public note described a React and Node prototype for organizing longitudinal personal information and AI-assisted reflection. It discussed OAuth-connected sources and psychological pattern exploration as possibilities, not as independently verified production integrations.

Its useful contribution was the problem framing: personal evidence changes over time, model outputs can sound more certain than they are, and mental-health software must expose uncertainty and professional escalation boundaries.

What the first concept did not establish

  • No clinical validation: it did not demonstrate diagnostic accuracy, treatment benefit or crisis suitability.
  • No production-data claim: the public note did not prove that every described connector or backend path was live.
  • No autonomous role: model-generated hypotheses could not replace clinician judgment or emergency services.
  • No historical release claim: the v0.1 label is used here to organize the portfolio timeline; it does not assert that a Git tag was published on 2026-06-25.

Lessons carried into v0.2

  • Use synthetic data for the public demonstration and make that status visible.
  • Separate participant, professional, gateway, model and database responsibilities.
  • Run safety checks on the original Spanish text before optional translation.
  • Keep model-weight changes offline, versioned and subject to approval.
  • Treat consent, deletion, auditability and human review as architecture, not footer text.

Why keep the original post

A portfolio should show evolution rather than rewrite history. The original PsychDeep article remains evidence of the early scope; this retrospective supplies the later context and an honest publication date.
