Current project

The current product line is PsychDeep 3. Its master branch contains the later vNext transition, canonical longitudinal analytics, a separate presentation of change versus deterministic safety risk, clinician-reviewable model signals, administrator-only provider selection and a supported local LM Studio inference path.
