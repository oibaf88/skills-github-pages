EudraVigilance API Workbench

A prototype for authorised EudraVigilance/EVDAS-style API access, public ADR aggregate analysis and exploratory disproportionality metrics.

Open the appProxy README

Why this app exists

A public portfolio demo should not pretend to have unrestricted access to EudraVigilance. The correct architecture separates three situations: authorised API access, direct sandbox testing, and public aggregate-data exploration.

01

Authorised API proxy

A Supabase Edge Function and a Render-ready Node service can proxy lawful authorised API calls without exposing upstream credentials in the browser.

02

Public aggregate analysis

The browser can analyse CSV/TSV matrices copied from permitted public aggregate sources such as adrreports.eu.

03

Disproportionality

ROR and PRR are implemented as exploratory screening statistics on drug-event-count matrices, not as incidence, causality or medical advice.

Regulatory boundary

EMA describes EudraVigilance as the system for managing and analysing information on suspected adverse reactions in the EEA. It supports ICSR exchange, early signal detection and improved product information, and access to EudraVigilance data depends on the EMA access policy. Public data are available through the European database of suspected adverse drug reaction reports.

The workbench therefore avoids any claim of unrestricted API access. Its API mode is only useful once lawful endpoint details and credentials are configured in Supabase or Render. Its public mode works locally in the browser and does not upload report tables to a backend.
